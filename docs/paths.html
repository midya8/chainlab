FINITE HIDDEN MARKOV MODELS · EXACT RATIONAL PROBABILITIES

A path is a decision.
It is not the uncertainty.

The most probable whole path can make more expected state errors. Marginal modes can form an impossible path. And equal state marginals can hide very different whole-path uncertainty.

Change the model below. Independent BigInt inference recomputes every probability and decision. Entropy is approximate, in nats. All statements condition on your supplied model and observations, not on ground-truth states.

1. Choose the evidence

Edit the complete model and observation sequence

Unsigned rational strings only, such as "2/3" or "0". Each row must sum to exactly one. 1–4 states, 1–8 symbols, 1–32 observations. Input fractions: 128 bits. Every reported fraction: at most 8,192 bits. Complex exact arithmetic may refuse an otherwise valid model; simplify denominators or shorten the sequence.

2. Decide what a wrong path costs

MAP minimizes whole-path 0/1 loss. Expected matches minimizes additive Hamming loss among supported paths. Product marginals is a different constrained objective, not a joint path probability. Unconstrained modes minimize Hamming loss without the support constraint.

Hamming loss counts wrong state positions, not wrong transitions. Expectations use the same full-window posterior. A smaller expected loss is a model-conditional decision statement, not evidence of better true-state recovery.

Locked and independent controls have the same five state marginals. Their whole-path entropies are ln(2) and 5·ln(2). Neither a MAP path nor a marginal table alone gives the full path distribution. Entropy is a property of this posterior, not a confidence or calibration promise.

Choose any numeric probability cell for its exact rational value. Impossible conditional rows are undefined, not silently normalized.

5. Check every decoding state

Each cell gives the best supported prefix ending in that state. Initial, transition and emission support all count. No forward prefix is a full-path probability. For product marginals, scores multiply state marginals; they never become the joint posterior.

All exact ties choose the lexicographically first whole index path, not a local predecessor tie rule. The original floating Viterbi API keeps its earlier rule unchanged.
